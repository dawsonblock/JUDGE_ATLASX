# reference_only/

This directory holds **read-only reference material** for the JUDGE_ATLAS project.

## Purpose

Files placed here are:

- Documents, specs, or code that informed the design but are not active production artifacts
- Third-party specifications or schemas that must not be modified
- Archived policy documents or prior-version specs kept for audit continuity

## Rules

1. **Never import** any Python file from this directory.
2. **Never modify** files here — they are immutable reference snapshots. If you need an updated version, place it elsewhere and note the provenance.
3. **No build tooling** should reference this directory.
